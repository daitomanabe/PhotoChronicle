# PhotoArchivePlanner UI - ユーザーマニュアル

このアプリケーションは、大量の写真・動画データを安全にアーカイブするための「計画作成（Phase 1）」ツールです。
複数のソース（HDD、SDカード、写真ライブラリ）をスキャンし、重複を排除した統廃合プラン（`plan.sqlite`）を作成します。

実際のファイルコピーは行わず、**データベースによる計画作成のみ** を行います（安全設計）。

---

## 主な機能

1.  **ソースの統合**: 複数のフォルダや「写真ライブラリ（.photoslibrary）」をドラッグ＆ドロップで追加できます。
2.  **重複排除**: SHA-256ハッシュを用いて、内容が完全に同一なファイルを検出・除外します。
    - 画面に「重複ファイル数（Duplicate Count）」がリアルタイムで表示されます。
3.  **追記モード（Append Feature）**: 
    - 過去に作成した `plan.sqlite` を読み込み、その続きから新しいソースを追加スキャンできます。
    - 以前のスキャン結果（ハッシュ値）は再利用されるため、無駄な再計算が発生しません。
4.  **高速スキャン**: 
    - 並列処理（Parallel Engine）により、複数のファイルを同時にハッシュ計算し、高速にデータベースを作成します（最大8並列）。

---

## 使い方

### 1. モードとデータベースの選択
画面上部の「Plan Database」パネルで、モードを選択してからデータベースを指定します。

- **New Plan (新規作成)**: 
    - 「Create / Save...」ボタンを押して、新しいファイル名（例: `plan-YYYYMMDD.sqlite`）を指定します。
    - **注意**: 指定したファイルが既に存在する場合、または実行時（Start Phase 1）に、既存のデータは **全て削除** され、ゼロからスキャンが始まります。
- **Append (追記モード)**:
    - 「Select Existing...」ボタンを押して、既存の `plan.sqlite` を選択します。
    - 過去の計画データ（スキャン済みハッシュ値など）が読み込まれ、その続きから新しいソースを追加できます。

### 2. ソースの追加 (Sources)
左側のパネルに、スキャンしたいフォルダや「写真ライブラリ」をドラッグ＆ドロップします。
- 複数の場所を登録可能です。
- 写真ライブラリはパッケージ（バンドル）の中身を自動的に解析し、元データ（Masters/Originals）のみを対象にします。

### 3. 出力先の指定 (Plan / Destination)
統合後のデータを保存する予定の **出力先ボリューム（フォルダ）** を指定します。
- 実際には書き込みませんが、データベースに「ここへ保存する予定（UUID記録）」として記録されます。

### 4. 実行 (Start Phase 1)
「Start Phase 1」ボタンを押すとスキャンが始まります。
- **Scanning**: ファイル一覧を高速に取得します。
- **Hashing**: SHA-256ハッシュを計算します（並列処理）。
- **Building Blobs**: 重複判定を行い、正規化（Canonical）されたリストを作成します。
- **Freezing**: 完了すると計画が確定（FROZEN）され、データベースが保存されます。

### 5. 結果の確認
画面右下のログパネルで進行状況を確認できます。
- **Sources**: スキャン対象の数
- **Discovered**: 見つかったファイル総数
- **Hashed**: ハッシュ計算完了数
- **Unique**: 重複を除いたユニークなファイル数
- **Duplicate**: 重複として除外されるファイル数

## 技術仕様

- **データベース**: SQLite3 (`plan.sqlite`)
    - すべてのメタデータとハッシュ値が保存されます。
    - 大規模データ（数百万ファイル）でも安定して動作します。
- **重複判定**: SHA-256
- **ファイル整理ルール**:
    - 出力パスは `DEST/YYYY/MM/DD/<ハッシュ>/filename` の形式で計画されます。
    - 日付情報はEXIF情報を優先し、なければファイルの更新日時（mtime/UTC）を使用します。

## 注意事項

- **Phase 2（実行）について**: 
    - このアプリは「計画（Plan）」を作るまでが仕事です。
    - 実際のファイルコピーは、作成された `plan.sqlite` を読み込む別のスクリプト（`executor.py` 等）で行います。
